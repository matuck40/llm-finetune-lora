# llm-finetune-lora

**New study project, in progress.** I am learning to fine-tune an open language model with LoRA, writing the code myself.

## Plan

1. Pick a small open model and a narrow task with a public dataset
2. Measure the base model on a held-out set before any training
3. Fine-tune with LoRA and measure again on the same set
4. Report the before and after, with what changed and what did not

Nothing here is production-grade yet; this README will track what is done.
